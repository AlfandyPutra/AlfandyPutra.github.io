------------------------------------------------------------
TIPS MENAMPILKAN LEBIH DARI 1 GAMBAR (GALERI):
------------------------------------------------------------
Jika 1 proyek memiliki beberapa gambar, pisahkan dengan tanda koma (,) pada atribut data-images di index.html:

Contoh:
data-images="project/bakasir-1.png, project/bakasir-2.png, project/bakasir-3.png"

Tombol panah kanan/kiri dan thumbnail otomatis muncul jika gambar lebih dari 1!

------------------------------------------------------------
CARA KERJA:
------------------------------------------------------------
Ketika kartu proyek atau tombol "Preview" ditekan, gambar proyek akan langsung terbuka di dalam jendela popup modal tanpa meninggalkan website.
Tombol "GitHub" di dalam kartu tetap berfungsi normal untuk membuka repositori GitHub di tab baru.
